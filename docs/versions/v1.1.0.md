# v1.1.0 - 2026-05-02

Smarter workout suggestions, leaner saved workout history, and a cleaner logging/editing experience.

---

### Added

**Suggestion Scoring**
- Continuous exercise recency penalties based on days since last performed instead of a fixed recent-session window
- Family recency penalties so related movements are gently deprioritized after a same-family exercise was performed
- `recency_decay` scoring config to control how quickly exercise and family repeat penalties fade per day
- `min_score_threshold` scoring config to drop low-quality suggestions during the normal selection pass
- Score breakdown support for family recency in selected exercises and the all-scores table

**Workout UI**
- Collapsible exercise cards with set-count badges while collapsed
- Collapsible history entries with exercise and set summaries
- A Disable action on suggested exercises that saves the exercise as disabled and refreshes suggestions immediately
- Click-to-select search results in the workout exercise picker; the Add button now commits the selected/input exercise
- New default core exercise: Crunches, including steps, breathing notes, and caution notes

### Changed

- Saved workouts now store only exercise name, mode, and sets; library metadata such as pattern, family, muscles, description, difficulty, priority, and enabled are stripped before persistence
- Past workout display and editing enrich lean saved exercises from the current exercise library so pattern labels and descriptions remain available in the UI
- Editing a workout now opens the logging area, scrolls to it, suppresses automatic last-session prefill, sets the correct reps/time mode, and opens exercise cards after sets are loaded
- Exercise enable/disable changes now refresh suggestions immediately
- Default scoring values now use `recency_penalty: 2.5`, `family_recency_penalty: 1.0`, `recency_decay: 0.65`, and `min_score_threshold: 1.0`

### Fixed

- Fixed saved workout history becoming bloated with exercise-library metadata
- Fixed edit-workout flows that could mix automatic last-session prefill with the workout being edited
- Fixed history rows being hard to scan once workouts contained multiple exercises and sets
- Fixed suggestion scoring that treated any repeated exercise within a recent-session window the same, regardless of how many days had passed
- Fixed score breakdowns missing the same-family repeat penalty shown in the suggestion table

### Internal

- Added an idempotent startup migration to strip stale exercise metadata from existing `workouts.json` files for `default` and all users
- Updated core logic tests to pass recency maps instead of recent exercise-name lists
- Removed `recency_history_sessions` from default scoring config in favor of day-based recency data
