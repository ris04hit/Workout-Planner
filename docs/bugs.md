# Bug Tracker

Bugs found manually during testing. Each bug will be resolved in the next version release.
Clear resolved bugs by moving them to the relevant version file in `docs/versions/`.

---

## Format

```
### [BUG-N] Short title

- **Where:** file or UI section where the bug occurs
- **Steps to reproduce:** numbered steps
- **Expected:** what should happen
- **Actual:** what actually happens
- **Priority:** Low / Medium / High / Critical
```
